# Poolday

**nz_Poolday**, my Nazi Zombies: Portable map, playable in the browser.

Play: https://oisinmg.ie/Poolday/

`docs/` is the published site. It is the official NZ:P web build (FTEQW compiled to WebAssembly) from
[nzp-team/nzp-team.github.io](https://github.com/nzp-team/nzp-team.github.io), with the stock maps removed
and Poolday added as `nzp/poolday.pk3`. The page boots straight into the map with `+map nz_Poolday`.

To rebuild after editing the map: download the official files into `upstream/`, then run `python tools/pack.py`.

NZ:P is made by the [NZP Team](https://github.com/nzp-team/nzportable) and runs on [FTEQW](https://fteqw.org).
